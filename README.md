# DOGE

## Overview

DOGE is a differentiable rendering-driven framework for extracting smooth and compact road networks from aerial imagery without curve-level vector ground truth. It combines:

- **DiffAlign**, which continuously optimizes the geometric alignment of a Bézier graph against target masks through differentiable rendering.
- **TopoAdapt**, which applies discrete graph operators to adapt the road network topology.

This discrete–continuous coupling enables accurate vector road reconstruction while preserving geometric smoothness and topological compactness.
